# Power BI dashboard build guide

## Import
1. Open Power BI Desktop.
2. Select **Get data → Text/CSV** and import `data/service_demand_synthetic.csv`.
3. Set `month` to Date and count fields to Whole number; set `median_wait_days` to Decimal number.
4. Name the table `ServiceDemand`.

## Suggested measures (DAX)
```DAX
Requests Received = SUM(ServiceDemand[requests_received])

Requests Completed = SUM(ServiceDemand[requests_completed])

Open Requests = SUM(ServiceDemand[open_requests_end_month])

Overdue Requests = SUM(ServiceDemand[overdue_requests])

Completion Rate % =
DIVIDE([Requests Completed], [Requests Received], 0)

Net Demand =
[Requests Received] - [Requests Completed]

Median Wait Days =
MEDIAN(ServiceDemand[median_wait_days])
```

## Page 1 — Executive overview
- KPI cards: Requests Received, Requests Completed, Open Requests, Completion Rate %, Median Wait Days.
- Line chart: monthly Requests Received and Requests Completed.
- Line chart: Open Requests over time.
- Slicers: Month, Region, Service Channel.

## Page 2 — Regional comparison
- Bar chart: Average Open Requests by Region.
- Bar chart: Completion Rate % by Region.
- Matrix: Region, Requests Received, Requests Completed, Completion Rate %, Median Wait Days.
- Tooltip or note explaining that raw counts are not population-adjusted.

## Page 3 — Data quality and interpretation
- Table of data-quality checks generated by `analyse.py`.
- Text box listing assumptions and limitations.
- Note: dataset is synthetic and must not be treated as official statistics.

## Design guidance
Use clear titles, descriptive labels, consistent date filters and accessible contrast. Avoid red/green performance judgements unless an approved target or threshold exists. Do not imply that a region is underperforming based solely on these synthetic counts.
